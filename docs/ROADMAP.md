# 路线图

当前优先级是人工监督下的**单关可靠执行**，不是扩大玩法范围或承诺无人值守通关。

## 重点

- **退出与恢复可靠性**：区分活战斗、暂停、结算与剧情；完善漏怪、超时及异常路径的退出确认。只有证据确认退出后才恢复目标面板，未知状态明确交给人工处理。
- **战术证据质量**：保持第一现场截图、生命变化、Copilot 动作及视频时间锚点可追溯；暴露时间偏差与缺失证据，帮助判断部署、技能时机及漏怪原因。
- **单关契约**：保持关卡身份、难度变体、静态校验和胜负判定在 MCP/CLI 中一致；用离线回归保护失败路径，并将离线覆盖与实机验证分开记录。

## 边界

- 关卡浏览与跨界面自动选关暂停；执行前仍需手动确认目标关卡面板，归位只覆盖可识别的结算、剧情、地图或详情界面。
- 肉鸽、保全派驻、悖论模拟虽有 MAA 桥接入口，但不是当前验收目标。
- 不计划采集账号实际技能等级、专精或模组。相关字段保留未知，理论末级数据仅作机制参考。
- 当前不提供任意作业自动修正、任意关卡通关或连续无人值守保证。
